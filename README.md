# 搜索词分析系统

基于积加开放平台 API 的亚马逊广告搜索词分析工具：本地运行、本地存储，自动同步广告报表并生成搜索词分析与优化建议。

## 下载

最新版本：**v1.2.2**

- Windows 免安装版：[下载 search-term-system-setup.exe](https://github.com/136435954/search-term-system-dist/releases/download/v1.2.2/search-term-system-setup.exe)
- [使用说明](使用说明.md)

## 本版更新（v1.2.2）

- 修正「累计点击」口径：改为历史统计时间段内的点击之和。此前当历史区间已包含新增时段（默认「近一年」包含「近 30 天」）时，同一批点击会被算两遍，点击 6~9 次的词可能被误判为达到 10 次决策门槛
- 两行制展示口径不变：历史累计仍是全区间累计，新增时段仍是该时段单独表现

## 功能

- 全店广告总览：花费 / 订单 / 销售额 / 曝光 / 点击 / CVR / ACoS + 近 14 日趋势
- 搜索词两行制分析（历史累计 / 新增时段）与优化建议
- 重点优化清单、广告组合视图、ASIN 维度、投放证据
- 增量同步（断点续传）、Excel 导出（52 工作表）
- 自动检查更新：配置页可手动检查，发现新版本弹窗提示
- GitHub 主页入口（左上角图标）

## 系统要求

- Windows 10 / 11
- 可访问积加开放平台（open.gerpgo.com）
- 需要积加开放平台 AppId / AppKey（在积加后台申请）

## 隐私与安全

- 凭证仅保存在本机 config.json，不随软件分发、不上传
- 数据全部存储在本机 data/ 目录
- 软件以本地服务方式运行（127.0.0.1），不对外网开放

## 使用

详见 [使用说明](使用说明.md)（首次使用三步：填凭证 → 同步数据 → 开始分析；内置 26 步新手教程）。
